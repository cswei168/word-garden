← 回到词光

每天的单词，一点就能开始。

免费使用，无需注册。安装后可从主屏幕独立打开。

iPhone / iPad

  1. 用 Safari 打开下方链接。如果在微信等应用内，先选择“在浏览器打开”。
  2. 点击 Safari 的分享按钮（方框加向上箭头）。
  3. 选择“添加到主屏幕”，再点“添加”。如果出现“作为网页 App 打开”，请开启。
  4. 回到主屏幕，点击“词光”图标。

安卓手机

  1. 用 Chrome 打开下方链接。
  2. 点击页面上的“安装到手机”；或打开浏览器右上角 ⋮ 菜单，选择“安装应用” / “添加到主屏幕”。
  3. 按提示确认，再从手机主屏幕打开“词光”。

分享给朋友

复制这个链接发给朋友，他们也可以按上面步骤安装。

使用前请看

首次联网打开应用，等页面底部出现“离线词库已就绪”，之后断网也能背词和默写。语音识别仍需网络和浏览器支持，识别一致不代表发音完全标准。

安装前如已学习，请在“学习计划”里导出备份；安装后若没有原进度，再导入备份。不同设备之间不会自动同步。

若网址本身被网络拦截或无法连接，添加到主屏幕也不能解决首次访问问题。
